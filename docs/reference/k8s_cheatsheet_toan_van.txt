Thực hiện trên cả 3 máy: Tắt SWAP (bộ nhớ ảo) sudo swapoff -a sudo sed -i '/ swap / s/^\(.*\)$/#\1/g' /etc/fstab (K8s sẽ crash ngay lập tức nếu phát hiện máy vẫn đang bật SWAP) Cấu hình mạng Kernel Linux cho Network cat <<EOF | sudo tee /etc/modules-load.d/k8s.conf overlay br_netfilter EOF sudo modprobe overlay sudo modprobe br_netfilter cat <<EOF | sudo tee /etc/sysctl.d/k8s.conf net.bridge.bridge-nf-call-iptables
